This is a simple four function calculator that I made using Rust. 
I am new to coding and this is my first project.
It has the ability to do basic addition subtraction multiplication and division.
It works by inputing your first number, selecting an opperator, inputing your second number, and pressing the equals button.
It saves your calcuated number your next calculation as the first number.
The clear button clears all of the values and resets the calculator.
I developed all of this by hand without the use of AI. 
The total time I spent working on this was about 12 hours.
This project is finished for now, probably, but I may come back to it later.
